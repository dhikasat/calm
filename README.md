# C.A.L.M — website

The public website for **C.A.L.M — Chronicle And Life Management**, a planner, focus timer, and
journal for iPhone, iPad, and Apple Watch.

- Home: https://dhikasat.github.io/calm/
- Support: https://dhikasat.github.io/calm/support.html
- Privacy Policy: https://dhikasat.github.io/calm/privacy.html
- Bahasa Indonesia: https://dhikasat.github.io/calm/id/

This repository holds only the published pages. They are generated from the app's own repository,
so changes made here directly are overwritten the next time the site is published.
